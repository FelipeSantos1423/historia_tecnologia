# História da Tecnologia

Site simples desenvolvido com HTML, CSS e JavaScript, apresentando um breve resumo sobre a evolução da tecnologia ao longo da história.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Objetivo

O objetivo deste projeto é praticar desenvolvimento web básico e apresentar informações sobre a História da Tecnologia de forma simples e visual.

## Como executar

1. Baixe ou clone o repositório
2. Abra o arquivo `index.html` no navegador
